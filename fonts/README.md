# Homepage font fallback

Helvetica Neue is the primary family, using the visitor’s installed font. No proprietary font file is redistributed.

Inter Variable 4.1 is the locally hosted fallback for Latin text and punctuation when Helvetica Neue is unavailable. Japanese text uses installed Hiragino Sans, Yu Gothic, Meiryo, or the browser’s sans-serif fallback. The Latin unicode ranges avoid requesting Inter solely for Japanese characters.

- Original WOFF2: https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1
- Official font: https://rsms.me/inter/
- License: SIL Open Font License 1.1, included as Inter-LICENSE.txt

The font binary is unchanged. No external font stylesheet or font service is required. Inter’s optional capital-G variant (cv10) keeps its fallback form closer to the primary family; optical sizing is automatic.
